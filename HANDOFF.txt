GOAL
Drone (3DR Solo, ArduCopter/OpenSolo) flies a lawnmower survey at ~15 ft. A Raspberry Pi 5 on the drone
runs YOLO to find litter, geotags each piece, records video, and after landing uploads NEW pieces to
Firebase so a consumer iOS app (user's "Litterbug" app) can show them for people to pick up.
An operator iOS app ("LB Operator") plans/flies missions and shows live camera + litter.

MODELS  (~/litter-model/)
- BEST: full1280_all/best.pt = ground (TACO+CLICK) + drone (UAVVaste) at imgsz 1280 whole frame.
  89% of litter found on 116 UAVVaste test photos, 104 false. On Pi as ~/yolo/all1280_rect_ncnn_model
  (NCNN exported at imgsz 736,1280 rectangular) = 4.96 fps on Pi CPU.
- Others: litter/ (ground only), v2/, v3/ (ground+drone tiles, 91%, 1.6 fps), runs/uavonly, full1280_uav.
- UAVVaste gotcha: GoPro photos have EXIF rotate tags; labels are on RAW pixels -> never exif_transpose,
  and pass numpy arrays (not PIL) to Ultralytics.

CODE  (~/litterbug/, copy to Pi ~/litterbug/, run with ~/yolo/venv)
- survey_logger.py   camera(30fps, lores 640x360 live stream) -> YOLO on newest full frame -> pose (MAVLink or --sim)
                     -> geolocate -> merge sightings within 3 m -> SQLite survey.db (WAL; fb_status/fb_id columns),
                     crops, frames, video.mp4 (--record), live JPEG (--live). --selftest checks map math.
- mission_server.py  HTTP API :8080 + operator.html. Plan (/api/plan), upload/start/pause/rtl/land via pymavlink,
                     runs logger, stops it on disarm, /stream (MJPEG live), /api/pieces (from DB, with status),
                     /api/runs + /runs/<run>/{pieces,video(range requests),crops/*}, converts videos to H.264,
                     after landing calls firebase_sync (upload only NEW pieces). Mid-flight Firebase checks were
                     REMOVED at user's request (check+upload after landing only).
- firebase_sync.py   dedupe vs Firestore (open item within 3 m -> "known", else "new"); skips --sim runs.
- survey_path.py     polygon -> lawnmower path, QGC .plan / Mission Planner .waypoints / preview.
- Pi venv has ultralytics, ncnn, pymavlink, firebase-admin installed. Scripts were copied to Pi BEFORE the
  latest changes -> RE-COPY all ~/litterbug/*.py + operator.html when Pi is back.
